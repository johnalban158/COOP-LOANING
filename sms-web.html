📫 Gmail Reminders
All reminders are sent automatically via Gmail (MailApp) using the email address on file for each member (col C of the Members sheet). No additional configuration is needed.
✓ Powered by Google MailApp — always free
✓ Rich HTML email with payment details sent to member email
✓ Official Receipt email sent on payment confirmation
⏰ Auto-Send Daily
Auto-send Gmail reminders at 8 AM daily for all members with upcoming dues.
Disabled — manual only
💡 Setup required:
Run createReminderTriggerOnce() once from Apps Script Editor to enable daily auto-send.

How Reminders Work
Scans active loans for payments due today, tomorrow, or overdue. Sends a rich Gmail notification to the member's email (col C). Click Send per row or Send All for bulk.
